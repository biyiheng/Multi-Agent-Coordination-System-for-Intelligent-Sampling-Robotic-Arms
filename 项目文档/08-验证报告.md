## 4. 常识逻辑约束修复与验证

### 4.1 框架级约束（Agent 底层）

[base_agent.py](c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/agents/base_agent.py) 的 `check_constraints()` 已在 `run()` 生命周期内置，覆盖四大条款：

1. **不可擅自决策** — `authorization_required` 必须有 `authorization` 令牌
2. **不可不懂装懂** — 禁止基于 `assumed` / `unverified_assumptions` 决策
3. **一切必须符合事实逻辑** — 数值必须有限（拒绝 NaN/Inf）
4. **辅助决策满足常识性要求** — 拒绝物理不可能值（关节角 > ±360° 等）

**本轮加固（Round 13）**：此前约束仅在 `run()` 的**输入**状态上校验。已在 `run()` 处理完成后新增对**输出**结果的约束校验（`out_constraint = self.check_constraints(result)`），使"符合事实逻辑 / 常识性要求"同样覆盖输出，杜绝 Agent 处理后在输出中产生 NaN/Inf/越界值的漏检。

**本轮加固（Round 14）**：`check_constraints()` 升级为**递归扫描**并对物理量增加**PWM 范围校验**：
- **递归非有限值扫描**：真实运行中 Agent 返回的物理量（`vision_result` / `motion_result` / `sampling_points`）常嵌套于 dict/list 中，旧实现仅检查顶层 float，会漏检嵌套 NaN/Inf。现通过 `_scan_non_finite()` 深度遍历捕获任意层级非法数值。
- **PWM 物理范围校验**：通过 `_check_pwm_range()` 校验舵机 PWM 必须在物理范围 **500..2500 μs** 内，拒绝负值/超范围等物理不可能值（`SERVO_PWM_MIN=500` / `SERVO_PWM_MAX=2500`）。

**覆盖性核验**：
- 5 个 Agent（motion / safety / vision / quality / sampling）均只覆写 `process()`，继承统一的 `BaseAgent.run()`，约束对所有 Agent 自动生效，无绕过路径。
- orchestrator 为纯协调器，其 `process_state()` 通过 dispatch 调用各状态处理器，每个处理器最终经 `agent.run()` 执行，守卫机制未被绕过；orchestrator 本身不产生机器人决策。
- 当前各 Agent 未主动声明 `authorization_required`/`assumed` 标记，故"不可擅自决策/不可不懂装懂"条款为**按需启用的安全网**：一旦未来某 Agent 声明需要授权或依赖假设，框架将自动拦截。事实逻辑与常识性条款为**始终生效**。

### 9.2 发现并修复的问题

| # | 位置 | 严重性 | 问题描述 | 修复 |
|---|------|--------|---------|------|
| 1 | `hardware/esp32_wifi.py` `_read_until()` | **高** | 超时判断 `time.monotonic() > _now() + effective` 中 `_now()` 在**循环内**每次重新求值，导致超时条件永远为假，对无响应 ESP32 会**无限循环** | 在循环前捕获 `deadline = _now() + effective`，循环内仅比较 `_now() > deadline` |
| 2 | `mobile_app/lib/core/ws_client.dart` `isConnected` | 低 | 三目运算 `_channel!.ready is! Future<dynamic> ? ...` 逻辑冗余（`ready` 恒为 Future），可读性差 | 简化为 `bool get isConnected => _channel != null;` |
| 3 | `esp32_firmware/esp32_wifi_provisioning.ino` `NVS_NAMESPACE` | 中 | `const int NVS_NAMESPACE = "smartarm";` 将字符串字面量赋给 `const int`，编译报错 | 改为 `const char *NVS_NAMESPACE = "smartarm";` |
