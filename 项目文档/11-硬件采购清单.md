## 2. 编码器加装（S1）—— 具体操作指南

> 目标：每个关节输出轴加装 AS5048 绝对值编码器，MCU 内闭环 PID 用编码器读数替代开环 PWM 假设位置。软件驱动已就绪：F103 SPL `SRC/encoder/y_encoder.c`、STM32H7 HAL `stm32h7/as5048_encoder.c`。

### 2.1 机械安装（每关节）
1. 将磁铁（Ø6×3 NdFeB）**居中**粘接在输出轴端面，偏心误差 ≤ 0.05mm（影响精度）。
2. 将 AS5048 PCB 对准磁铁上方，芯片中心与轴心对中，气隙控制在 0.5–1.5mm。
3. 固定 PCB（螺丝/双面胶），确保静止不随轴转动。
4. 对 6 关节逐一重复；**安装完成后做零位标定**：将关节置于机械零位，读取并记录原始值作为零偏。

### 2.2 电气接线（AS5048 SPI）
| 信号 | STM32 引脚（示例） | 说明 |
|------|-------------------|------|
| SCLK | SPI 时钟（SPI1_SCK，PA5） | SPI 时钟 |
| MOSI | SPI1_MOSI（PA7） | 命令/数据出 |
| MISO | SPI1_MISO（PA6） | 数据入 |
| CSn | 独立 GPIO（如 PC0） | 片选，软件控制 |
| VDD | 3.3V | 供电 |
| GND | GND | 共地 |

接线要点：
- SPI 模式：CPOL=0、CPHA=1（AS5048 数据手册要求，已在驱动 `SPI_Init` 配置）。
- 每路编码器独立 CS 引脚，SCLK/MOSI/MISO 可共享同一 SPI 总线。
- **上电顺序**：先给 AS5048 供电再读数据；片选拉低前后需留出时钟建立时间。

### 2.3 软件启用与验证
1. 在 `main.c` 的 `system_init()` 已调用 `encoder_init()`；确认 SPI1 时钟与 GPIO 已使能。
2. 主循环 `io_upgrade_run()` 会周期调用 `encoder_read_angle()` 读取角度。
3. **验收**：
   - 转动关节，角度单调变化、无跳变（原始值 0–16383 连续）。
   - 静止时读数稳定（抖动 < ±1 LSB）。
   - 定位误差 ≤ 0.01°、重复定位精度 ≤ 0.05mm（规划 §1.3 验收口径）。

```bash
# 若在树莓派侧验证（软件模拟串口回传角度），可运行编码器诊断
python -m rpi_control.scripts.diagnose_encoder --port /dev/ttyAMA0
```

## 3. CAN 总线升级（S2）—— 具体操作指南

> 目标：将关键控制/安全帧迁移至 CAN 1Mbps，引入 CRC32 + 重发 + 优先级仲裁。软件驱动已就绪：F103 SPL `SRC/can/y_can.c`、STM32H7 HAL `stm32h7/can_link.c`。

### 3.1 电气接线
| 信号 | STM32 引脚 | CAN 收发器 | 总线 |
|------|-----------|-----------|------|
| CAN_TX | PA12（CAN1_TX，重映射 PB9） | TJA1050 TXD | — |
| CAN_RX | PA11（CAN1_RX，重映射 PB8） | TJA1050 RXD | — |
| CANH | — | TJA1050 CANH | 总线 CANH |
| CANL | — | TJA1050 CANL | 总线 CANL |

接线要点：
- **120Ω 终端电阻**必须在总线两端各接一个（首尾节点），否则高速信号反射导致通信失败。
- 共地：各节点 GND 互联（星型共地，避免地电位差损坏收发器）。
- 屏蔽双绞线：CANH/CANL 用双绞线，屏蔽层单端接地。
- 若 STM32 3.3V 而收发器 5V：选 3.3V 兼容型（SN65HVD230）或加电平转换。

### 3.2 波特率配置
`y_can.h` 已按 APB1=36MHz 配置 **1Mbps**：`CAN_BAUD_PRESCALER=2`、`CAN_BS1=13tq`、`CAN_BS2=4tq`、`CAN_SJW=1tq`（总 18tq）。所有节点必须使用**相同位时序**。

### 3.3 帧 ID 优先级与 CRC
- 帧 ID 低 4 位作为优先级（`CAN_PRIO_*`）：急停/系统 `0x0` 最高，关节闭环 `0x1`，传感器 `0x2`，视觉 `0x3`。CAN 仲裁时 ID 越小优先级越高，保证急停帧低延迟。
- `can_send()` 在负载后追加 **CRC32** 尾字节，接收端 `can_crc32()` 校验，失败丢弃并计数（`rx_crc_fail`）。
- 重发机制：发送失败按 `CAN_MAX_RETRY` 重试，超上限返回 `CAN_ERR_TIMEOUT`。

### 3.4 软件启用与验证
1. `system_init()` 已调用 `can_init()`；确认 CAN1 时钟与引脚重映射（AFIO->MAPR 置位）已配置。
2. 主循环 `io_upgrade_run()` 调用 `can_receive()` 轮询。
3. **验收**：
   - 心跳帧以 1kHz 周期发送，抖动 < 100µs（规划 §2.3 验收口径）。
   - 人为制造坏帧，确认 CRC 检出（`rx_crc_fail` 递增）并可重发。
   - 断开总线，确认 < 100ms 内触发安全停车（配合 Safety Agent）。

```bash
# 总线健康监测
python -m rpi_control.scripts.diagnose_can --baud 1000000
```

## 4. 主控替换（S4）—— STM32H7 迁移步骤

1. 硬件更换：将 STM32F103 主板替换为 STM32H743 核心板，迁移供电/引脚。
2. 外设资源核对：H7 提供多路 SPI（编码器 ×6）、2×CAN（总线 + 诊断）。
3. 软件：将 F103 SPL 版 `y_encoder.c`/`y_can.c` 迁移至 H7 HAL 版 `stm32h7/as5048_encoder.c`/`can_link.c`（骨架已就绪，补全 MX 配置）。
4. 控制周期：H7 硬件 FPU/DSP 支撑 10ms → 1ms 控制周期；在 1ms 定时器中断中执行闭环 + 前馈。
5. 验收：闭环带宽 ≥ 20Hz（规划 §1.3 口径）。

## 5. 替换实施排期建议

| 阶段 | 内容 | 依赖 | 验收 |
|------|------|------|------|
| 立即 | 采购 AS5048 ×6 + TJA1050 + 120Ω 电阻 | 无 | 到货质检 |
| 第 1 周 | 编码器单关节试点加装 + 接线 + 软件读角度 | 编码器硬件 | 角度单调、稳定 |
| 第 2 周 | 6 关节全部加装 + 零位标定 + 闭环 PID 调参 | 试点通过 | 定位 ≤0.01° |
| 第 2–3 周 | CAN 总线组网（STM32 + RPi + 收发器） | 收发器到货 | 1Mbps 心跳、坏帧检出 |
| 第 4 周 | S4 主控 STM32H7 迁移 | H7 板到货 | 1ms 周期、闭环带宽 |
| 中期 | 工业相机 + Jetson Orin（M1） | 相机/载板到货 | 6D 位姿 ≤1mm/1° |
| 长期 | 双通道急停 + 安全继电器 + IP54（L2） | 安全器件到货 | 急停 <30ms |

## 6. 风险与注意事项

| 风险 | 缓解 |
|------|------|
| 磁铁偏心率导致编码器精度下降 | 安装时用芯棒对中，偏心 ≤0.05mm |
| CAN 未加终端电阻导致通信失败 | 首尾节点各加 120Ω |
| 3.3V/5V 电平不匹配烧毁收发器 | 选 3.3V 兼容型或加电平转换 |
| 编码器磁场干扰/退磁 | 远离电机磁极、选用高矫顽力磁铁 |
| 替换主控导致回归 | 保留现有运动学/轨迹/Agent 基线，新分支推进 |
