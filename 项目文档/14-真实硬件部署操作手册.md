## 2. 阶段一：F103 固件构建与烧录

### 2.1 前置
- 已安装 STM32CubeIDE 工具链（本仓库 Makefile 使用其 `arm-none-eabi-gcc`）。
- 硬件：ST-Link 调试器、目标板（STM32F103C8T6）。

### 2.2 构建
在 `stm32_firmware/` 目录执行：

```bash
make all
```

预期输出 `BUILD SUCCESSFUL!`，产物 `OUT/STM32F103C8T6.hex` / `.bin` / `.elf`。
（已确认编译通过：text=23560, data=112, bss=7272。）

### 2.3 烧录
```bash
# 方案A：ST-Link CLI（Makefile 已定义 flash 目标）
make flash

# 方案B：STM32CubeProgrammer
STM32_Programmer_CLI -c port=SWD -w OUT/STM32F103C8T6.hex -v -rst
```

### 2.4 验证
- 上电后 UART 输出启动信息。
- 若已接入 AS5048，`encoder_read_angle()` 返回有效角度；磁场异常时 `error_count` 递增并返回 `ENC_ERR_MAGNETIC`。
- CAN 层初始化成功返回 `CAN_OK`；可发送测试帧并由 CAN 分析仪确认 ID 与 CRC。

## 3. 阶段二：动力学前馈启用（树莓派）

### 3.1 确认模块
模块已位于 `rpi_control/motion/dynamic_feedforward.py`，包含：
- `GravityCompensator`：重力补偿 G(q)（已修正力矩单位，N·mm）。
- `FrictionModel`：库仑 + 粘滞 + Stribeck 摩擦。
- `DynamicFeedforwardController.compute_smoothed()`：前馈 + 一阶低通 + 力矩限幅 + **NaN/Inf 防护与滤波器重置**。

### 3.2 启用
在运动链中实例化并在底层关节闭环前叠加前馈：

```python
from rpi_control.motion.dynamic_feedforward import (
    DynamicParams, LinkDynamicParams, FrictionParams, DynamicFeedforwardController)

params = DynamicParams(
    link_params=[LinkDynamicParams(mass_kg=0.3, com_mm=[0,0,20])],
    friction=[FrictionParams(coulomb_nmm=5.0, viscous_nmm_per_rads=0.1)],
)
ff = DynamicFeedforwardController(params, torque_limit_nmm=[200.0]*6)
tau = ff.compute_smoothed(q, q_dot)   # 输入 NaN/Inf 时安全返回 0
```

### 3.3 验证
```bash
python -m pytest rpi_control/tests/test_dynamic_feedforward.py -q
python -m pytest rpi_control/tests/test_h7_closed_loop.py -q
```

## 4. 阶段三：Agent 与模型服务启动

### 4.1 Linux 兼容性说明
`start_all.sh` 已在**真实 Git bash / Linux bash** 下通过 `bash -n` 语法校验（数组定义 `MODELS=(...)`、ROS2 节点循环、`set -euo pipefail` 均有效）。此前报错为 Windows STM32CubeIDE 精简 shell 不支持数组所致，非真实 Linux 问题。

### 4.2 一键启动
```bash

./start_all.sh --check      # 环境/模型/Agent 自检（推荐先跑）
./start_all.sh              # 本地源码方式启动 5 Agent + 模型服务
```

```bash

./start_all.sh --jetson     # 额外启动 Jetson 视觉节点（M1，需平台支持）
```

### 4.3 停止
```bash

```

## 6. 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 烧录后无 UART 输出 | 波特率/引脚不匹配 | 确认 38400 8N1，核对 main 配置 |
| 编码器读数异常 | 磁场异常/接线错误 | 检查 AS5048 磁场诊断，`error_count` 计数 |
| CAN 无法发送 | 总线无终端电阻/波特率不匹配 | 检查 120Ω 终端与位时序 |
| `start_all.sh` 报错 | 使用了 Windows 精简 shell | 使用真实 Linux bash / Git bash 执行 |
| Agent 不启动 | 模型缺失 | 先 `./start_all.sh --check`，补训练模型 |
