## 2. 快速安装

```bash
# 1) 进入项目根目录
cd Multi-Agent-Coordination-System-for-Intelligent-Sampling-Robotic-Arms

# 2) 安装 Python 依赖
pip install -r rpi_control/requirements.txt

# 3) （可选）固件烧录：STM32F103
cd stm32_firmware && make all && make flash   # 需要 ST-Link + arm-none-eabi 工具链
```

---

## 3. 一键启动（推荐）

使用根目录 `start_all.sh`（真实 Linux 环境）：

```bash
./start_all.sh --check     # ① 环境/模型/约束自检（不启动）
./start_all.sh --stress    # ② 压力测试 + 生成报告（部署前必做）
./start_all.sh             # ③ 启动全部 5 个 Agent + 模型服务
./start_all.sh --log       # 跟随主服务与编排器日志
./start_all.sh --stop      # 停止所有服务
```

> **首次部署建议顺序**：`--check` → `--stress` → 启动 → 访问健康检查。

---

## 4. 启动后验证

```bash
# 健康检查
curl http://<设备IP>:8000/api/health

# 查看进程与 PID
ls .run/            # main.pid / orch.pid
tail -f .run/main.log
```

各 Agent 经 `BaseAgent.run()` 启动，约束护栏（不可擅自决策 / 符合事实逻辑）自动生效。

## 5. 可选部署方式

### 5.1 Docker
```bash
docker compose -f rpi_control/docker-compose.yml up -d
```

### 5.2 ROS2 / Jetson（工业级升级）
```bash
./start_all.sh --ros2            # 以 ROS2 节点方式启动 Agent（需已装 ROS2）
./start_all.sh --jetson          # 额外启动 Jetson 视觉节点
./start_all.sh --ros2 --jetson   # 组合
```
> 未检测到对应环境时脚本会自动回退到本地源码方式，不影响启动。

### 5.3 systemd 服务
```bash
# 安装服务（脚本路径：rpi_control/scripts/rpi-sampling-arm.service）
sudo cp rpi_control/scripts/rpi-sampling-arm.service /etc/systemd/system/
sudo systemctl enable --now rpi-sampling-arm
```

## 6. 移动端 App 部署（Android / iOS）

> 双端 App 为 Flutter 工程（`mobile_app/`），与服务端通过 REST + WebSocket 多端互通中枢 `/ws/hub` 通信。详细说明见 [mobile_app/README.md](../mobile_app/README.md) 与 [04-部署文档 §13](04-部署文档.md)。

### 6.1 环境要求

- Flutter SDK ≥ 3.0（建议 3.16+）
- Android：Android Studio + Android SDK；iOS：macOS + Xcode
- 服务端已运行（`./start_all.sh` 或 `uvicorn rpi_control.web.server:app`）

### 6.2 构建与安装

```bash
cd mobile_app
flutter pub get
flutter analyze                # 静态检查（0 error 再发布）
flutter build apk --release    # Android 产物: build/app/outputs/flutter-apk/app-release.apk
flutter install                # 安装到已连接 Android 设备
# iOS（需 macOS）:
flutter build ios --release    # 产物: build/ios/iphoneos/*.app
```

### 6.3 配置服务端地址

- 默认连接 `192.168.1.100:8000`，可在 App「设置」页修改并持久化，也可改 `lib/core/app_config.dart`。
- 手机与树莓派须同一局域网；跨网访问需在路由器做端口映射并启用 HTTPS。
- iOS 明文 HTTP 需在 `Info.plist` 的 `NSAppTransportSecurity` 中允许本地网络明文。

### 6.4 首次使用流程

1. 打开 App → 注册账号（与服务端共享账号体系）→ 登录。
2. 「控制」页：6 关节滑杆 / 笛卡尔坐标 / 夹爪 / 回零 / 急停。
3. 「监控」页：实时传感器数据 + 多端设备在线状态（WebSocket 推送）。
4. 「WiFi」页：扫描 AP → STA 连接 / AP 创建热点 / 状态查询。
5. 「设置」页：修改服务端地址。

## 7. WiFi 模块（ESP32）部署

> 两种接入方式详见 [04-部署文档 §14](04-部署文档.md)；服务端通过 `rpi_control/hardware/esp32_wifi.py` 的 AT 指令接口控制，无硬件时可运行**模拟模式**。

### 7.1 方案 A：树莓派 + 外接 ESP32 AT 模块（推荐）

- ESP32 刷 **Espressif AT 固件**，通过 UART 接树莓派（默认 `/dev/ttyUSB0`，波特率 115200）。
- 服务端 WiFi API（`/api/v1/wifi/*`）自动发现并控制，支持 STA 连接 / AP 热点 / 扫描 / 复位。
- 无硬件开发/测试：代码自动回退模拟模式，`test_multient_interop.py` 已覆盖验证。

### 7.2 方案 B：ESP32 独立配网固件

- 用 Arduino IDE 烧录 `esp32_firmware/esp32_wifi_provisioning/esp32_wifi_provisioning.ino`（ESP32 Dev Module）。
- 首次上电进入 SoftAP 配网：手机连热点 `SmartArm-XXXX` → 访问 `192.168.4.1` → 填写目标 WiFi SSID/密码。
- 保存后自动连接 STA，串口输出 `WIFI CONNECTED / SSID=xx / IP=xx`；长按 GPIO0 5 秒清除配置重新配网。

### 7.3 验证 WiFi API

```bash
TOKEN=$(curl -s -X POST http://<设备IP>:8000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"<你的密码>"}' | python -c "import sys,json;print(json.load(sys.stdin)['access_token'])")

curl -H "Authorization: Bearer $TOKEN" http://<设备IP>:8000/api/v1/wifi/status
curl -H "Authorization: Bearer $TOKEN" http://<设备IP>:8000/api/v1/wifi/scan
```

## 8. 常见问题快速定位

| 现象 | 处理 |
|------|------|
| `--check` 报模型缺失 | 先完成训练/复制模型到 `models/`，再重跑 |
| 启动后无健康响应 | 查看 `logs/` 与 `.run/main.log`，确认 8000 端口未被占用 |
| 急停误触发 | 按 [16-故障排查速查表](16-故障排查速查表.md) 中"急停触发"章节定位 |
| 双网丢失告警 | 检查主/备网络物理连接，见速查表"COMMUNICATION_TIMEOUT"章节 |
| 压力测试失败 | 依据 `reports/stress_test_results.json` 定位，参考 [13-压力测试方案](13-压力测试方案.md) |
| App 无法连接服务端 | 确认手机与树莓派同网，检查 App「设置」页服务端地址 |
| App 登录 401 | 先在注册页注册账号，确认密码正确并已携带 Bearer token |
| iOS 请求被拒 | `Info.plist` 配置 `NSAppTransportSecurity` 允许本地网络明文 |
| ESP32 无法配网 | 长按 GPIO0 5 秒清除配置重新进入 SoftAP；核对 SSID/密码 |
| WiFi API 401 | 未携带 Bearer token，先登录获取 token |
