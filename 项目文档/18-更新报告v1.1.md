## 1. 版本说明

v1.1 为 v1.0 的**功能增强与工程化完善**版本，遵循语义化版本规范（次版本号递增表示新增功能且保持向后兼容）。本次更新聚焦三大方向：

1. **后台控制模块全面接入数据库**：机械臂 / 视觉 / 系统配置等控制模块状态由内存改为 SQLite 持久化，并补齐全模块**增删改查（CRUD）**能力；
2. **双端 App 工程化落地**：下载安装 Flutter SDK 完成构建验证，界面统一 Material 3 主题美化，配置持久化；
3. **质量保障**：全量回归测试、全面代码检索与 Bug 修复。

> 说明：v1.0 已交付的多端互通（鉴权 / 设备中心 / WebSocket 中枢 / ESP32 WiFi）与 Flutter App 基础功能在 v1.1 中保持兼容并继续增强。

---

## 2. v1.1 新增 / 变更内容

### 2.1 后台控制模块数据库接入（新增）

| 模块 | 持久化内容 | 存储方式 | 效果 |
|------|-----------|---------|------|
| 机械臂控制 | `arm_status`（关节位置 / 夹爪 / 急停 / 运动状态） | `ConfigRepository` | 服务重启后自动恢复机械臂状态 |
| 视觉控制 | `vision_state` + `vision_thresholds`（各颜色阈值） | `ConfigRepository` | 阈值调整后持久化，重启不丢失 |
| 系统配置 | 各配置项读写 / 单项删除 / 备份恢复 | `ConfigRepository` | 配置中心化，避免硬编码 |

### 2.2 全模块 CRUD 补齐（新增 / 增强）

此前部分模型仅具备「读 / 写」，v1.1 补齐**增删改查**完整能力：

| 模型 | 仓储类 | 路由前缀 |
|------|--------|---------|
| 用户 | `UserRepository`（新增 update / delete） | `/api/v1/auth/*` |
| 设备中心 | `DeviceRepository`（新增 delete） | `/api/v1/devices/*` |
| WiFi 状态 | `WifiStateRepository`（新增 delete） | `/api/v1/wifi/*` |
| 系统配置 | `ConfigRepository`（单项删除 / 备份恢复） | `/api/v1/system/config*` |
| 样本 | `SampleRepository`（完整 CRUD，`sample_routes.py`） | `/api/v1/samples` |
| 闭环工程 6 模型 | `EvaluationReportRepository` 等 6 个仓储（完整 CRUD，`loop_routes.py`） | `/api/v1/loop/*` |

### 2.3 双端 App 界面美化（增强）

- 统一 **Material 3 主题**：圆角卡片、统一输入框 / 按钮 / 导航栏样式、夜间模式；
- 新增复用组件：`SectionHeader`（分区标题）、`StatusCard`（状态卡片）；
- 控制页重构：急停 / 夹爪状态卡片、关节滑杆分区、笛卡尔坐标区、回零 / 急停按钮区；
- 服务端地址持久化（`shared_preferences`），重启自动恢复；
- 新增 UI 冒烟测试 `mobile_app/test/smoke_test.dart`。

### 2.4 工程化落地（新增）

- 本地安装 **Flutter SDK**（`.flutter_sdk/`，不入库），`flutter analyze` 0 error、`flutter test` 通过；
- `pubspec.yaml` 依赖整理；AndroidManifest 网络权限 / 明文流量配置就绪。
