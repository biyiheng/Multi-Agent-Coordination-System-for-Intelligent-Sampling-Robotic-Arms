## 1. 版本说明

v1.2 依据《改进计划.md》对系统进行**通信协议、实时安全与 Agent 能力**的升级，并完成**全量模型重训练**。本次更新遵循语义化版本规范（次版本号递增，保持向后兼容），聚焦四大方向：

1. **统一帧格式通信协议**：新增标准帧协议（`帧头 | 目标地址 | 源地址 | 命令字 | 数据长度 | 数据 | CRC16 | 帧尾`），CRC16 校验 + 坏帧/篡改帧丢弃，供 STM32 / OpenMV / ESP32 通信层复用；
2. **实时安全监控增强**：传感器采集链路（100Hz 量级）接入安全状态机，新增温度 / 电流过载检测，1ms 安全周期内联动保护性停止；
3. **Agent 能力增强**：Vision Agent 多帧融合滤波（EMA）提升检测稳定性；Sampling Agent 分层采样（等距 + 边界增强）提升覆盖均匀性；遥测推送率 10Hz → 20Hz；
4. **数据重爬 + 全量模型重训练**：合法爬取公开工业数据并重建训练集，重训 motion_ik / safety / quality / collision 四个模型，独立精度校验全部通过。

> 说明：v1.1 已交付的数据库 CRUD、多端互通（鉴权 / 设备中心 / WebSocket 中枢 / ESP32 WiFi）、双端 App 等功能在 v1.2 中保持兼容并继续增强。

## 2. v1.2 新增 / 变更内容

### 2.1 统一帧格式通信协议（新增）

对应《改进计划.md》§5 通信协议设计：

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧头 | 2B | 固定魔数 `0xAA 0x55`，用于字节流同步 |
| 目标地址 | 1B | 0=host，1=STM32，2=OpenMV，3=ESP32，0xFF=广播 |
| 源地址 | 1B | 命令发起方 |
| 命令字 | 1B | move_joint / move_all / estop / get_status 等 |
| 数据长度 | 1B | 载荷长度（上限 255B） |
| 数据 | N B | 逗号分隔文本载荷 |
| CRC16 | 2B | CCITT（poly=0x1021），覆盖目标地址~数据字段 |
| 帧尾 | 2B | `0x0D 0x0A` |

实现与接入：

- 新增 [frame_protocol.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/hardware/frame_protocol.py)：`Frame` 数据模型、`crc16()`、`encode_frame()` / `decode_frame()`、`extract_frames()` 流式解析、便捷命令构造；
- [stm32_comm.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/hardware/stm32_comm.py) 新增帧模式（`set_frame_mode()` / `send_frame()` / `frame_move_joint()` / `frame_emergency_stop()` 等），与既有 `#CMD!` 文本协议并存可切换；
- [servo_controller.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/hardware/servo_controller.py) 在帧模式下自动走帧协议封装运动 / 停止 / 急停命令；
- [main.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/main.py) 从 `settings.yaml protocol.frame_enabled` 读取开关并启用。

### 2.2 遥测推送率升级至 20 Hz（变更）

对应《改进计划.md》§4.1 状态上报任务 20Hz：

- [telemetry.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/web/websocket/telemetry.py) 默认推送率 10Hz → 20Hz（`DEFAULT_PUSH_RATE = 20`）；
- 新增 `set_push_rate()`，可由 `settings.yaml protocol.telemetry_push_rate` 配置覆盖（[server.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/web/server.py) 启动时注入）。

### 2.3 实时安全传感器过载监控（新增）

对应《改进计划.md》§4.1 传感器采集任务 100Hz / 安全监控任务 1kHz：

- 新增 `SafetyEventType.TEMPERATURE_OVERLOAD` / `CURRENT_OVERLOAD` 事件；
- [realtime_safety.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/safety/realtime_safety.py) 新增 `update_joint_sensors()` 注入温度 / 电流采样值，`_check_sensor_overload()` 在 1ms 安全周期内按关节判限；
- 温度过载（>70°C）/ 电流过载（>3A）触发 `PROTECTIVE_STOP` 联动，温度预警（>55°C）触发 warning。

### 2.4 Vision Agent EMA 多帧融合滤波（新增）

- [vision_agent.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/agents/vision_agent.py) 在既有中值滤波基础上新增 `get_smoothed_position()`，对 (cx, cy, area) 做指数移动平均（α=0.3），抑制帧间抖动；
- 历史中断自动重置 EMA 状态，避免陈旧均值污染；`reset_ema()` 供目标切换时调用。

### 2.5 Sampling Agent 分层采样边界增强（变更）

- [sampling_agent.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/agents/sampling_agent.py) `_stratified_sampling()` 在等距分层基础上新增**边界增强**：沿四条边补充采样点，避免边缘覆盖不足；
- 使用 `seen` 集合去重角点，保证每个角点只采样一次。

### 2.6 数据重爬与模型重训练（新增 / 变更）

- **数据重爬（合法）**：更新爬取工具 [web_scraper.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/training/web_scraper.py) / [real_data_crawler.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/training/real_data_crawler.py)，从公开渠道合法采集机器人规格 / 舵机参数 / 缺陷样例等真实数据；

- **全量重训**：[retrain_all.py](file:///c:/Users/毕以恒/Desktop/zidongaixiangmu/rpi_control/training/retrain_all.py) 依次重训四个模型（motion_ik 200 epochs / safety 250 / quality 300 / collision 150×5 ensemble），并执行碰撞召回率门控（≥0.85）。

### 2.7 正式回归测试（新增）
